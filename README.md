# Pi Agent 工作空间 · 本地预览版

版本：0.9.0-preview.2

这是「网页界面 + 本机服务」的可迁移源码发行包，不是云端网站，也不是包含 Node.js 的免安装应用。不需要原作者的 Pi 安装目录，不依赖 8504/8514 服务。

## 启动

1. 安装 **Node.js 22 或更高版本**（官方：https://nodejs.org/）。
2. 完整解压。macOS 双击 `start.command`；Windows 双击 `start.bat`；Linux 在终端运行 `sh start.sh`。
3. 浏览器自动打开「项目测试」内置示例。也可复制启动窗口显示的地址。
4. 查看流程或模拟对话后，点击 **复制为我的项目**，在三个区域填写自己的 API 配置。未知渠道的 Key 仍需填写 Base URL，模型列表需确认后读取。
5. 保持启动窗口开启；停止时按 Ctrl+C。关闭浏览器标签不等于停止服务。

也可在解压目录执行 `node scripts/local-release.mjs` 或 `npm start`。**不需要 npm install**，本包无第三方运行时 npm 依赖。若 macOS 阻止未签名启动脚本，可在终端切换到解压目录执行上述 Node 命令；不要关闭系统安全保护。

## 内置示例

- 「项目测试」：多 Agent 协作的闭环平台，保留九节点结构、两条执行分支和用户确认节点。
- 示例对话为人工编写并明确标注，不含原作者的消息、API Key、附件、记忆、渠道或绝对文件路径。
- 示例中的模拟操作仅存在当前页面，刷新后还原，不调用模型、不计费用。
- 复制只取内置流程；新项目从零进度开始，拥有新的对话 ID，需自行配置渠道。示例中临时新增的节点不会自动复制。
- 左侧保留示例入口；新项目可从「＋」创建。学习与生活目前是入口占位，并未接入完整业务。

## 数据与安全

数据默认在当前操作系统用户主目录的 `.pi-agent-workspace` 中；启动窗口会显示完整路径。程序与数据分开，更新时替换程序目录即可，不删除数据目录。

- 仅监听 `127.0.0.1`，使用空闲端口；不可直接当公网多用户服务使用。
- 项目和聊天存储在 `projects`；API Key 在 `connections` 中独立保存，**本地未加密**。Windows 下不要把数据放在共享账户或共享目录，POSIX 文件模式不等于 Windows ACL。
- 模型发送会将消息、最近20条有效历史及附件、项目目标和上游记录发送给你确认的渠道，可能计费。
- 不自动读取原 Pi 的配置，不提供任意命令、服务器文件、MCP 或原 Pi 全局管理接口。
- 未接入流式回复、中止、自主工具执行、长期记忆及多人登录。
- 用量仅显示接口实际返回的数据；不虚构成本、内部思维链或执行成果。
- 不要将数据目录、密钥、日志或使用后的电脑目录上传 GitHub。

备份：停止程序后备份完整数据目录。当前项目文件绑定绝对路径；跨电脑搬迁已有个人数据尚未实现，**不要直接复制到另一绝对路径并声称迁移成功**。本发行包保证全新机器可初始化新数据，不代表已有数据迁移功能完成。

同一数据目录只允许一个实例。若启动提示锁定，先关闭另一个窗口；异常退出后确认启动进程已停止，再删除数据目录的 `.instance.lock`。不要在程序运行时删锁。

可选设置：`PI_WORKSPACE_DATA_DIR` 为数据目录的绝对路径；`PI_LOCAL_PORT` 为端口（默认 0，自动选择）；`--no-open` 禁止自动打开浏览器。不提供外网监听开关。
